# 🏍️ AKIRA 3D — Interactive Cyberpunk Experience

> Uma experiência web 3D imersiva e interativa inspirada no lendário universo cyberpunk de **AKIRA** e Neo-Tokyo.

---

## 🌟 Destaques do Projeto

- **Cenário 3D Interativo**: Modelo tridimensional de alta fidelidade renderizado via WebGL com **Three.js**.
- **Animações Conectadas ao Scroll**: Efeitos dinâmicos de câmera, iluminação cinemática e rotação utilizando **GSAP & ScrollTrigger**.
- **Estética Cyberpunk Premium**: Iluminação HDRI, efeitos de vidro (glassmorphism), paleta de cores neoclássica e tipografia impactante.
- **Design 100% Responsivo**: Otimizado para telas de alta resolução em desktops e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **Core**: HTML5, CSS3 (Custom Design System), JavaScript (ES6+)
- **3D & WebGL**: Three.js, GLTFLoader, OrbitControls
- **Animações & Scroll**: GSAP, ScrollTrigger, ScrollSmoother
- **Hospedagem**: Vercel

---

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Led-New/Akira.git
   ```

2. Entre no diretório do projeto:
   ```bash
   cd Akira
   ```

3. Abra o arquivo `index.html` em um servidor local (ex: Live Server ou VS Code Extension).
